# fitflow-redesign

FitFlow HCI redesign project



The following content is recommended for the repository's README.md:

\# FitFlow Redesign



Human-centered redesign of the FitFlow fitness tracking app, addressing personalization,

social isolation, and nutrition-logging friction identified through user research.



\## Repository Structure

\- frontend/   — Flutter mobile + web client

\- backend/    — NestJS API services

\- ai-service/ — AI recommendation engine and computer vision (food recognition) service

\- docs/       — Tech stack summary, comparison matrix, architecture diagram, ADRs



\## Technology Stack

\- Frontend: Flutter (iOS, Android, Web)

\- Backend: Node.js / NestJS

\- Database: PostgreSQL, Redis, Firebase Realtime Database

\- Auth: Auth0

\- AI/ML: TensorFlow / TensorFlow Lite



See docs/tech-stack-summary.md and docs/adr/ADR-001-technology-stack.md for full rationale.



\## Getting Started

1\. Clone the repository

2\. cd frontend \&\& flutter pub get

3\. cd backend \&\& npm install

4\. cd ai-service \&\& pip install -r requirements.txt
